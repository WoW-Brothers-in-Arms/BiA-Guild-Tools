# Alts (Main ↔ Twink) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Players mark one character as main; the addon finds their other characters on the account, shares the group with the guild and shows it in a roster column (switchable with Professions), the roster tooltip and a `/bia alts` window.

**Architecture:** A new shared `RosterColumn.lua` owns the roster's spare column slot and an own column dropdown; Professions moves onto it. The new `Modules/Alts/` splits pure data logic (`Groups.lua`, fully unit-tested) from the module glue (`Alts.lua`: comm, column, tooltip, slash) and the window (`Window.lua`).

**Tech Stack:** Lua 5.1 (WoW: Forever, interface 16001, modern/Retail UI), busted + luacheck via `scripts/check.sh`, fake client in `spec/support/wow.lua`.

**Spec:** `docs/superpowers/specs/2026-11-11-alts-design.md`

## Global Constraints

- Runs in WoW: Forever only. Before using any Blizzard frame, template or API not already used in the addon, check it exists on the `forever` branch of wow-ui-source (Forever has real differences to Retail).
- Every new game global the addon reads goes into `read_globals` in `.luacheckrc`.
- Every new string: key in `Locales/enUS.lua` first, then `Locales/deDE.lua`. German UI says "Twink"/"Twinks" (e.g. "Twink von %s", column "Twinks"); English says "Alt"/"Alts".
- Module key `alts`, slash `/bia alts`, addon message prefix `BiaAlts`, protocol version `"1"`.
- Wire format follows Professions (`|`-separated, protocol version second): `G|1|<main>|<chosen 0|1>|<t>|<alt>,<alt>,...` and `R|1`. GUIDs are sent without the `Player-` prefix and get it back on receive. (Spec wrote `:` – `|` is used to match the existing modules.)
- Timestamps `t` use `GetServerTime()` when available, else `time()` (clients' local clocks differ).
- Characters are always keyed by GUID; name, class, level and online state come from the guild roster only.
- Stale received groups are dropped after `90 * 24 * 3600` seconds.
- Shared column choice: `BiAGuildToolsDB.rosterColumn` = `"prof" | "alts" | false`; when unset, `false` if `modules.professions.column == false`, else `"prof"`.
- Tooltip shows at most 6 other characters, then "+ n more".

## Review Focus

1. **Spoofed groups:** a message whose sender is not itself in the group it sends (main or alts) must be dropped – otherwise anyone can claim anyone's characters. Test in Task 4.
2. **Own characters vs. received data:** a received group must never move one of *my* characters out of my own group; my own group always wins locally. Test in Task 3.
3. **Player switches main:** the old group (keyed by the old main) must disappear, not linger next to the new one. Test in Task 3.
4. **Roster not loaded yet / player not in guild:** at login `GetNumGuildMembers()` can be 0; recording the own character must wait for roster data instead of pruning all own characters. Test in Task 4.
5. **Long groups:** a player with many alts must not produce a message over 255 bytes; split messages with the same `t` must be merged, not replace each other. Test in Task 3.

### Task 3: Alts data logic (`Modules/Alts/Groups.lua`)

Pure functions, no WoW API calls except via arguments. Exposed as `ns.AltGroups`.

**Files:**
- Create: `BiAGuildTools/Modules/Alts/Groups.lua`
- Modify: `BiAGuildTools/BiAGuildTools.toc` (add before `Modules\Version\Version.lua`)
- Test: `spec/alt_groups_spec.lua`

**Interfaces:**
- `roster` everywhere = `{ [guid] = { name = string, level = number, classFile = string, online = bool } }`
- `group` = `{ main = guid, alts = { guid, ... }, chosen = bool, t = number }`
- Produces:
  - `EffectiveMain(own, roster) -> guid|nil, chosen:bool` – `own = { chars = { [guid] = true }, main = guid|nil }`. Chosen main if it is in `own.chars`; else the char in `own.chars` with the highest `roster[guid].level` (ties: lowest GUID string), `chosen = false`; nil if `own.chars` is empty.
  - `OwnGroup(own, roster, t) -> group|nil`
  - `Encode(group) -> { string, ... }` – one or more `G|1|...` messages, each ≤ 250 bytes, same `t`, every message carries main and chosen; GUIDs without `Player-`.
  - `Decode(text) -> group|nil` – nil on wrong kind/version/garbage; GUIDs get `Player-` back and must match `^Player%-%d+%-%x+$`.
  - `Merge(groups, incoming, ownChars)` – mutates `groups` (keyed by main GUID):
    - same main, same `t`: union of alts;
    - same main, newer `t`: replace; older `t`: ignore;
    - then every char of `incoming` is removed from any *other* group with older `t`; groups left with neither alts nor a chosen main are deleted;
    - chars in `ownChars` are never taken by an incoming group whose main is not in `ownChars` (stripped from `incoming` before merging).
  - `Merge` sets `group.seen = now` (local `time()`, passed as 4th argument: `Merge(groups, incoming, ownChars, now)`) on the stored group, also when an equal `t` is re-received.
  - `Prune(groups, now, maxAge)` – deletes groups with `seen < now - maxAge`. (Not `t`: `t` only changes when the owner edits the group, so an active but unchanged group would expire.)
  - `Index(groups) -> { [guid] = group }` – every main and alt to its group.

- [ ] **Step 1: Write failing tests** (`spec/alt_groups_spec.lua`, load via `Wow.new().ns.AltGroups`):
  - `EffectiveMain`: chosen main wins; unchosen → highest level, `chosen == false`; chosen main no longer in `chars` → fallback.
  - `Encode`/`Decode` round trip: `{ main = "Player-1-0000AAAA", alts = { "Player-1-0000BBBB" }, chosen = true, t = 1700000000 }` → `{ "G|1|1-0000AAAA|1|1700000000|1-0000BBBB" }` → decodes back to an equal table.
  - `Decode` returns nil for `"G|2|..."`, `"X|1|..."`, a bad GUID.
  - `Encode` with 40 alts: every message `#msg <= 250`; decoding and merging all of them yields all 40 alts.
  - `Merge`: newer `t` replaces; older ignored; char B moving from group A (t=1) to group C (t=2) is only in C; player switching main from A to B (new group keyed B containing A, t newer) removes group A.
  - `Merge` with `ownChars = { B = true }`: incoming foreign group listing B does not take B.
  - `Prune`: group last seen over 90 days ago removed; group with old `t` but recent `seen` kept.
